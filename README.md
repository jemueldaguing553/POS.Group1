# POS Group 1 - Small Business Point of Sale System

## Group Name

**POS Group 1**

## Project Title

**Small Business Point of Sale System (SBPOSS)**

---

## How to Use (Step-by-Step)

1. Open the system 

2. Login using the provided account

   * Username: `cashier`
   * Password: `1001`

3. Browse available products

4. Add items to the cart

5. Adjust quantity if needed

6. Proceed to payment

7. Enter cash amount

8. Confirm payment

9. View and check receipt

10. Go to summary to view transactions

---

## System Modules & Features

### Login Module

* User authentication
* Session management

### Sales Module

* View products
* Search and filter by category
* Add/remove items from cart
* Adjust item quantity

### Payment Module

* Input cash amount
* Calculate total and change
* Confirm transactions

### Receipt Module

* Display transaction details
* Show purchased items and totals
### Summary Module

* View daily sales
* View all transactions
* Search transactions by ID
